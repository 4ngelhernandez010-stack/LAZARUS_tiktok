Política de privacidad y cookies de LAZARUS

Última actualización: 18 de octubre de 2026

1. Responsable y alcance

El responsable que publica LAZARUS es Angel Gabriel Hernandez Flores. Contacto: 4ngelhernandez.010@gmail.com. Esta política describe el sitio informativo de GitHub Pages y la aplicación de escritorio para Windows. El país de establecimiento del responsable y la dirección comercial no se indican aquí; esta política no afirma cumplimiento con una jurisdicción concreta.

2. Datos tratados y minimización

El sitio es estático: no incluye cuentas, formularios, anuncios, analítica, píxeles ni scripts de seguimiento. No pedimos datos para leer estas páginas. Si escribes voluntariamente al correo publicado, tu mensaje y dirección se tratarán para responder y gestionar la consulta; comparte solo lo necesario y evita enviar contraseñas, tokens o información sensible.

En la aplicación, el contenido que introduces o importas para organizar ideas, proyectos, medios y videos se almacena localmente en tu equipo. La integración de TikTok puede tratar el identificador de cuenta, nombre visible, avatar y permisos concedidos. La aplicación guarda una copia del estado de cuenta y permisos en su base de datos local; las credenciales de desarrollador y tokens se guardan en un archivo cifrado con Windows DPAPI para el usuario de Windows actual.

3. Finalidad, consentimiento y control

Los datos locales se usan para las funciones que solicitas. No se envían a LAZARUS mediante este sitio. Cuando eliges conectar TikTok, inicias sesión en TikTok y autorizas los permisos que allí se muestran; puedes cancelar el proceso o revocar el acceso desde TikTok. Cuando solicitas transferir un video como borrador, la aplicación transmite el video seleccionado a TikTok. Revisa el contenido y los permisos antes de continuar.

No hay formulario web actualmente, por lo que no recopilamos datos mediante campos ni mostramos una casilla de consentimiento de formulario. El enlace de correo abre tu aplicación de correo; enviar el mensaje es una decisión voluntaria. Si en el futuro se incorpora un formulario, se actualizará esta política y el formulario tendrá etiquetas claras, campos mínimos, navegación por teclado y una opción de consentimiento separada y no premarcada cuando sea necesaria.

4. Proveedores e integración de terceros

  • TikTok: Login Kit y API para autorización, perfil básico y transferencia de video. TikTok controla sus propios servicios y tratamientos. Consulta su política de privacidad.
  • GitHub Pages: aloja este sitio. GitHub puede procesar datos técnicos de solicitudes y registros de servidor conforme a sus políticas; consulta la declaración de privacidad de GitHub.

El sitio no carga recursos de terceros, fuentes externas ni herramientas analíticas. No podemos controlar las prácticas de los servicios de terceros; revisa sus políticas antes de usarlos.

5. Cookies y seguimiento

El código de estas páginas no establece cookies propias ni utiliza almacenamiento local, analítica, publicidad o seguimiento. GitHub y TikTok pueden usar tecnologías propias en sus servicios, incluidas las necesarias para seguridad o funcionamiento, bajo sus respectivas políticas. Este sitio no ofrece actualmente un panel de consentimiento porque no activa cookies opcionales. Si se añaden cookies opcionales o analítica en el futuro, se actualizará esta política y se solicitará consentimiento antes de activarlas cuando corresponda.

6. Conservación, desconexión y eliminación

Los datos de la aplicación permanecen en tu equipo hasta que los elimines. Desconectar TikTok elimina de LAZARUS los tokens y datos locales de la cuenta conectada; las credenciales de desarrollador permanecen guardadas para permitir una conexión posterior. Desinstalar la aplicación puede no borrar sus datos de usuario; elimina por separado la carpeta de datos de LAZARUS y las copias de seguridad que hayas creado. La eliminación local no borra los datos que TikTok ya haya recibido.

7. Seguridad

Los tokens y credenciales de TikTok se protegen mediante Windows DPAPI vinculada al usuario de Windows actual. Mantén protegido tu dispositivo y tu sesión. Ningún método puede garantizar seguridad absoluta.

8. Privacidad de menores y cambios

LAZARUS no está diseñado para recopilar datos de menores a través de este sitio. Usa la integración de TikTok conforme a los requisitos de edad y condiciones vigentes del servicio. Publicaremos aquí la fecha de revisión cuando cambien de forma material el sitio o el tratamiento descrito.

9. Solicitudes

Para consultas sobre privacidad, solicitudes relativas a datos que hayas enviado por correo o dudas sobre esta política, escribe a 4ngelhernandez.010@gmail.com. Los datos de la aplicación se guardan principalmente en tu equipo, así que puedes administrarlos allí; para datos mantenidos por TikTok, contacta también a TikTok.
