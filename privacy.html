Política de privacidad de LAZARUS

Última actualización: 18 de octubre de 2026

1. Responsable y alcance

El responsable de LAZARUS es [NOMBRE DEL RESPONSABLE]. LAZARUS es una aplicación de escritorio para Windows. Esta política describe los datos procesados por la aplicación y su integración con TikTok.

2. Datos que se guardan en el equipo

La aplicación guarda localmente los datos que introduces o importas para organizar temas, frases, proyectos, medios y videos, además de registros de estado y actividad necesarios para sus funciones. Los archivos de usuario se guardan en el equipo donde se ejecuta LAZARUS.

Si conectas TikTok, LAZARUS recibe y conserva el identificador de la cuenta, nombre visible, URL del avatar y permisos concedidos. Las credenciales de la app y los tokens de acceso y renovación se guardan en un archivo cifrado mediante Windows DPAPI para el usuario de Windows actual. Una copia del estado de la cuenta y sus permisos también se guarda en la base de datos local.

3. Datos enviados a TikTok

Al iniciar sesión, el navegador se comunica con TikTok para que autentiques la cuenta y concedas permisos. LAZARUS usa las API de TikTok para completar la autorización, consultar el perfil básico, renovar o revocar la autorización y, si solicitas la función de borrador, transferir el video seleccionado a TikTok. TikTok procesa esos datos según sus propias políticas y condiciones.

4. Dónde se procesan los datos

En esta versión, la base de datos y los archivos de trabajo se guardan localmente en el equipo. LAZARUS no necesita una cuenta central de usuario ni un servidor propio para ejecutar sus funciones principales. Los datos necesarios para las funciones de TikTok se transmiten directamente a los servicios de TikTok cuando usas esas funciones. No introduzcas en LAZARUS datos de otras personas sin autorización.

5. Conservación, desconexión y eliminación

Los datos locales permanecen en el equipo hasta que los elimines o desinstales/borres los datos de LAZARUS. Desconectar TikTok revoca la autorización e elimina de LAZARUS los tokens y la información de cuenta conectada; las credenciales de desarrollador permanecen guardadas para que puedas volver a conectar. También puedes revocar el acceso desde la configuración de tu cuenta de TikTok. Las copias de seguridad creadas por ti deben eliminarse por separado.

6. Seguridad

Los tokens y credenciales de TikTok se cifran con Windows DPAPI vinculada al usuario de Windows actual. Protege el acceso a tu sesión de Windows y a los archivos de tu equipo. Ningún método de almacenamiento o transmisión puede garantizar seguridad absoluta.

7. Menores y cambios

Usa LAZARUS de acuerdo con los requisitos de edad y las condiciones de TikTok. Esta política puede actualizarse si cambia el tratamiento de datos o las funciones de la aplicación; se mostrará la fecha de la última actualización.
