# Sitio público de LAZARUS para GitHub Pages

Este sitio contiene la página principal, los términos y la política de privacidad. **Todavía no está listo para publicarse:** reemplaza en `terms.html` y `privacy.html` `[NOMBRE DEL RESPONSABLE]` y `[CORREO DE CONTACTO]` por datos reales. Revisa también las descripciones de datos y funciones antes de publicar.

Publica esta carpeta como raíz de un único repositorio público. Si el repositorio se llama `lazarus-legal`, las URL del sitio tendrán esta forma:

- Inicio: `https://TU-USUARIO.github.io/lazarus-legal/`
- Términos: `https://TU-USUARIO.github.io/lazarus-legal/terms.html`
- Privacidad: `https://TU-USUARIO.github.io/lazarus-legal/privacy.html`

En GitHub, abre **Settings → Pages**, selecciona la rama `main` y la carpeta `/ (root)`, y guarda. Espera a que Pages publique el sitio; abre cada enlace en una ventana privada para comprobar que es público. Después pega los enlaces de términos, privacidad e inicio en TikTok Developer Portal y verifica las URL en **URL properties**.

La URL final depende del nombre de usuario y del repositorio que elijas. No envíes ni publiques aquí Client secrets, tokens u otras credenciales.
