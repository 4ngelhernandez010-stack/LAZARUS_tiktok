# Sitio público de LAZARUS para GitHub Pages

Este sitio contiene la página principal, los términos y la política de privacidad. Confirma que los datos de contacto y las descripciones de datos y funciones sigan siendo correctos al actualizar LAZARUS.

Este sitio está publicado desde la raíz del repositorio público `4ngelhernandez010-stack/LAZARUS_tiktok`:

- Inicio: `https://4ngelhernandez010-stack.github.io/LAZARUS_tiktok/`
- Términos: `https://4ngelhernandez010-stack.github.io/LAZARUS_tiktok/terms.html`
- Privacidad: `https://4ngelhernandez010-stack.github.io/LAZARUS_tiktok/privacy.html`

En GitHub, abre **Settings → Pages**, selecciona la rama `main` y la carpeta `/ (root)`, y guarda. Espera a que Pages publique el sitio; abre cada enlace en una ventana privada para comprobar que es público. Después pega los enlaces de términos, privacidad e inicio en TikTok Developer Portal y verifica las URL en **URL properties**.

No añadas aquí Client secrets, tokens, bases de datos, videos ni otros datos locales de usuario.
